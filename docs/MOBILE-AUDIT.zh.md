# 移动端样式评估

## 范围与证据

覆盖 PWA 的320/360/390/430px 竖屏，320/400px 短高度，以及640×320、844×390横屏。测试使用无头 Chrome，不等于 Safari 或 Android 真机键盘验证。模型测试使用隔离 DSH 的实际目录；压力测试只修改展示文字，不添加模型 ID 或可选模型。未操作生产会话。

## 已确认并修复

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 运行中同时显示代审批、模型、停止、发送时，发送被挤出窄屏 | 模型名按剩余空间收缩，停止/发送不收缩；移动端停止紧凑显示，目录保留宽度，不新增一行 | `ui-model-check.sh` 隔离 DSH，四种宽度检查完整边界和最小尺寸 |
| 审批区与固定底栏占满短视口，输入操作在屏幕外 | 底栏限制高度、可收缩并滚动，正文保留最小高度，短视口横幅限制高度 | `question-ui-check.mjs` 隔离 Relay/PWA，12条审批和32个子代理，六组短视口/横屏检查边界与滚动可达性 |
| 320px 下等待审批状态与菜单使会话标题几乎归零 | 移动端状态改圆点，保留 DOM 文字和提示，标题保留最小宽度 | 源样式浏览器测试中320px标题约82px |
| 无断点的长标题/目录横向溢出 | 标题与路径允许换行并约束宽度 | 长内容源样式几何测试 |
| 工具/子代理展开入口只有15～18px高 | 手机披露入口至少32px，子代理/顶部/子记录按钮至少36px | 源样式测量及真实 details 点击 |
| 小输入字号有 iOS 聚焦放大风险 | 问题、队列、筛选和重命名输入改16px | 计算样式验证；真机仍待确认 |
| 子代理操作行过窄 | 按钮允许换行，文字限制在容器内 | 窄屏源样式测试 |
| 子代理后台轮询反复插入加载文字；翻更早记录保留旧位置 | 后台轮询不插入加载行，手动更早页回到顶部 | 现有执行记录生命周期浏览器回归；精确滚动锚点仍需强化 |
| Markdown 浏览器回归使用已过时的连接选择器 | 检查当前连接按钮 | 加密重放和 Markdown 场景通过 |

子代理详情使用主消息流的 Markdown 样式和紧凑字号，但只展示简约的最新输出：隐藏委派的用户角色提示与原始启动回执，工具只保留摘要/状态，不提供手动刷新或分页按钮。最新有界窗口不是完整消息历史，底层记录仍保留。打开时定位到最新可见记录，后台轮询不强制滚动正在查看较早文字的读者。

另外回归了目录创建的校验/取消/失败/等待/确认、消息流子代理关联与刷新保留、完整历史、Markdown 和代码/表格独立滚动。

## 保留风险和后续事项

- **真机**：未验证 iOS Safari/安装版 PWA 的键盘、visualViewport 偏移、安全区、浏览器工具栏、字体缩放、VoiceOver/TalkBack 和手指点击精度。32～36px 比原先改善，但并非所有入口达到推荐44px。
- **极短视口**：可能需要滚动底栏才能操作发送或审批，不隐藏审批。模型浮层仅向上定位，极端键盘视口可能高度不足，尚无真机复现。
- **目录选择**：深层路径和 Home/Up 并排会占较多纵向空间，弹窗仍可滚动，未确认有不可达操作；可进一步做可展开的路径行。
- **焦点与无障碍**：关闭最后一个闲置子代理、问题提交、队列编辑结束后，焦点元素可能消失而没有明确落点。侧栏打开后的屏幕阅读器主内容隔离、大范围动态通知需要专门验证。
- **滚动**：正文在底栏/视口改变后的跟随，以及子代理实时替换时的阅读锚点，仍需记录ID与像素坐标测试；功能场景通过不代表精确滚动策略完善。
- **独立正确性问题**：队列刷新尚未像子代理目录那样按会话代次隔离，旧会话延迟响应可能覆盖当前队列。队列编辑 Enter 也缺少问题输入已有的 IME 保护。本次如实记录，不在样式补丁中无专门测试地混改。
- **原生**：本次评估针对 PWA，没有执行 Swift/macOS 验证，也不改变跨端能力协议。

## 执行检查

服务生产 PWA 的脚本前先运行 `npm run check` 构建。模型脚本使用 `bash scripts/ui-model-check.sh` 启动隔离 DSH。其他场景使用 `node --import tsx scripts/<name>.mjs`；`mobile-content-ui-check.mjs` 是源 CSS 测试，可用普通 Node。源样式测试不能单独证明真实运行时组件组合正确，因此需要同时保留运行时和样式场景。
