# 图片消息

图片传输与模型视觉能力是两回事。当前固定版本的 DSH Host 支持图片输入，并在接收前校验所选模型，但公开模型目录不暴露输入模态。Turnwire 不通过名称猜测，也不修改模型配置来假装支持。支持图片传输的会话仍可能因当前模型不支持而拒绝图片，客户端须保留草稿并显示错误。

已安装 DeepSeek 适配器的一部分运行时模型声明支持图片。当前 Codex bridge 配置只有模型 ID/名称，默认纯文本；能列出该路由不代表桥接服务能处理图片。接口与传输测试不等于真实提供商识图准确性验证。

## 有界输入

初版最多两张 PNG/JPEG/WebP/GIF，每张解码后最多256KiB，总计512KiB。附图文本限制16,000字符，确保 JSON 和 base64 在既有传输限制内。拒绝 SVG、任意 URL 和主机路径作为图片输入。PWA 可缩小/重新编码所选照片并提示；不处理图片尺寸的客户端必须明确拒绝超限文件。

`session.message` 接收可选 `images`，每项 `{mediaType,data,name?}`，其中 data 是规范 base64。只有附图时才允许空文本。不支持的 runtime 在发送前拒绝；DSH 在入队/steer 前校验实际模型和图片字节。图片会交给所选模型服务处理；仅选择图片不会提前上传。

## 存储和读取

Turnwire 历史只记录标准化的不透明图片引用与元数据，不记录 base64 图片正文。DSH 负责标准化和持久存储。`session.image` 只能读取指定 Turnwire 会话已引用的图片，通过同一认证本地或加密远程连接分块返回，不暴露公共图片 URL 或任意文件读取，也不泄露模型/DSH 凭据。

历史与文本导出保留图片元数据说明，不将图片字节塞进文本导出。修改排队文本不得悄悄把附图消息变成纯文本。失败请求不得生成看起来发送成功的本地图片消息。

## 验证边界

真实隔离 DSH 浏览器测试已确认：配置为纯文本的 bridge 在推理前拒绝图片，页面保留草稿。本地/加密远程传输、仅引用历史、会话范围读取和持久化使用确定性 runtime 测试；浏览器覆盖选图/粘贴/预处理、移除、失败保留和预览。协议、适配器、会话范围、传输及 UI 测试不能证明提供商正确识别了某张图片。真机相册、实际模型推理、原生 macOS 编译需独立验证并如实汇报。测试不得自行生成运行时模型 ID 或目录项。
