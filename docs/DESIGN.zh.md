# Turnwire 客户端设计

Turnwire 是开发者的会话工作台。它唯一的职责，是让同一项本地任务可以从另一台设备上被看清、被操作。

使用冷调纸面画布 `#f5f6f8`，白色表面 `#ffffff`，蓝灰侧栏 `#edf0f5`，主墨色 `#243142`，次级墨色 `#647184`，以及克制的蓝色 `#2f5ec4`。标题在 macOS 上使用 Avenir Next，正文使用平台系统字体，技术输出使用系统等宽字体。原生 macOS 遵循系统材质与控件。

桌面端：窄会话侧栏、宽而可读的对话区、紧凑的设备连接栏。手机端：对话占满屏幕，配一个刻意保留的会话抽屉。识别性元素是连续性栏，它显示实际连接的 Mac 与所选会话；它描述真实状态。审批位于输入框旁，带操作内容与一次性决定。避免把设置面板做成主界面。

空、加载中、离线、runtime 不可用和错误状态都要说明下一步操作。不虚构项目、任务、指标或输出。Demo runtime 始终带有标注。尊重键盘导航、焦点可见性与减弱动态效果。连接密钥在专门的连接视图中输入，除非用户选择记住该设备，否则只保留在会话存储中。
