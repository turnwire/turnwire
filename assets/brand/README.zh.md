# Turnwire Logo 素材

| 文件 | 背景 | 用途 |
| --- | --- | --- |
| [turnwire-logo-transparent.png](turnwire-logo-transparent.png) | 透明 | 将深色 Logo 放在浅色背景上。 |
| [turnwire-logo-light.png](turnwire-logo-light.png) | 不透明暖白色 | 独立展示，或上传为头像。 |

两张 PNG 均为 1254 × 1254 像素，包含图形标志和 Turnwire 字标。素材保留生成时的原始概念图，没有缩放或裁剪；属于位图，不含可编辑的矢量文件。
