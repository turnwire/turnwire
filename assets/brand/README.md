# Turnwire logo assets

| File | Background | Use |
| --- | --- | --- |
| [turnwire-logo-transparent.png](turnwire-logo-transparent.png) | Transparent | Place the dark logo on a light background. |
| [turnwire-logo-light.png](turnwire-logo-light.png) | Opaque warm white | Standalone presentation or upload as a profile picture. |

Both PNG images are 1254 × 1254 pixels and include the symbol and Turnwire wordmark. These are the original generated logo concepts, preserved without resizing or cropping. They are raster images; editable vector artwork is not included.

The phone page uses the **transparent** one: its light background is the page's, so the transparent file drops straight in, and it is a third of the size. `apps/remote-web/public/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` and `favicon-32.png` are the symbol cut from it (the lockup is stacked, symbol rows 239–823 and wordmark rows 891–1048); the light file stays for standalone use.
